# crawl4ai_scraper

This project provides a web interface for scraping URLs using the crawl4ai package.

## Project Structure

- **backend/:** Python backend code.
- **frontend/:** Streamlit frontend code.
- **docker/:** Docker-related files.
- **.env:** Environment variables.
- **config.yaml:** Application parameters.
- **.gitignore:** Git ignore file.
- **requirements.txt:** Backend Python dependencies.
- **guidance.md:** LLM guidance file.

## Setup

1.  Install Python dependencies: `pip install -r requirements.txt`
2.  Run crawl4ai setup: `crawl4ai-setup`
3.  Run the Streamlit app: `streamlit run frontend/app.py`
